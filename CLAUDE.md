# aguard — страж агентов

Прочитать перед работой: `docs/design.md` — замысел, три слоя (хуки, aguard, cl), что входит, порядок работ и открытые вопросы.

## Правила
- Go, один демон с одним конфигом; общие части (разбор транскриптов, процесс → сессия, давление машины) — из библиотеки akit (`~/git/akit`), не копией.
- Новое ограничение агентам (потолок памяти и т. п.) — только с «да» пользователя; по умолчанию aguard наблюдает и пишет, а не душит.
  Зачем: сторож не вводит потолков, отказов и снятий, о которых пользователь не знает
- Сигналы наблюдателей — только письмом сессии (лиду, мастеру, `night.also_to`). Новый наблюдатель перед выкаткой — засеять его состояние старыми событиями: `graft install` сразу перезапускает демон.
  Зачем: сигналы сторожа не приходят в каналы пользователя без его «да»
- Бриф проверяющему (суб-агент, мутанты, чужой код): любой `go test` — только `graft exec --heavy -- …`, без `| tail`/`| grep` (пайп теряет код выхода); упор в потолок — провал мутанта. Бойцы worker ограничены сами (`-mem`); свои прогоны без мутантов — `graft test -- -count=1 <пакеты>`.
  Зачем: пока у сессии нет потолка памяти, тест проверяющего не уводит ноут в своп
- Репозиторий закрытый; открывать и заводить другие репозитории — только с пользователем.
