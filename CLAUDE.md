# aguard — страж агентов

Прочитать перед работой: `docs/design.md` — замысел, три слоя (хуки, aguard, cl), что входит, порядок работ и открытые вопросы.

## Правила
- Go, один демон с одним конфигом; общие части (разбор транскриптов, процесс → сессия, давление машины) — из библиотеки akit (`~/git/akit`), не копией.
- Перенос из procguard, tmpguard, cl и chooks — с их владельцами; правка chooks, хуков и settings Claude Code — только с «да» пользователя на конкретную правку.
- Новое ограничение агентам (потолок памяти и т. п.) — только с «да» пользователя; по умолчанию aguard наблюдает и пишет, а не душит.
- Сигналы наблюдателей — только письмом сессии (лиду, мастеру, `night.also_to`); Telegram и другие каналы пользователя — только с его «да» (28.10 на сигналы сторожа в группе Дайджеста: «не надо так», a46a53c). Новый наблюдатель перед выкаткой — засеять его состояние старыми событиями: `graft install` сразу перезапускает демон.
- Бриф проверяющему (суб-агент, мутанты, чужой код): любой `go test` — только `graft exec --heavy -- …`, без `| tail`/`| grep` (пайп теряет код выхода); упор в потолок — провал мутанта. Причина: 2026-11-01 мутант guiwatch съел 13,5 ГБ — своп и фризы ноута; без `--heavy` потолка нет (`memory.max=max` у scope агента), с ним — потолок graft по умолчанию, без свопа (`graft exec -h`). Бойцы worker ограничены сами (`-mem`); свои прогоны без мутантов — `graft test -- -count=1 <пакеты>`.
- Репозиторий закрытый; открывать и заводить другие репозитории — только с пользователем.
