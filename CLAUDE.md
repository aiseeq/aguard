# aguard — страж агентов

Прочитать перед работой: `docs/design.md` — замысел, три слоя (хуки, aguard, cl), что входит, порядок работ и открытые вопросы. Решения оттуда не пересматривать молча — только обсудив с пользователем.

## Правила
- Go, один демон с одним конфигом; общие части (разбор транскриптов, процесс → сессия, давление машины) — из библиотеки akit (`~/git/akit`), не копией.
- Гейт и коммит — через graft и glint, как в соседних проектах (`.graft.yaml`, `.glint.yaml`); коммитить и пушить по готовности.
- Перенос из procguard, tmpguard, cl и claude-hooks — с их владельцами; правка claude-hooks, хуков и settings Claude Code — только с «да» пользователя на конкретную правку.
- Новое ограничение агентам (потолок памяти и т. п.) — только с «да» пользователя; по умолчанию aguard наблюдает и пишет, а не душит.
- Репозиторий закрытый; открывать и заводить другие репозитории — только с пользователем.
